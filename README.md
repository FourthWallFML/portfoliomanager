# PAT - Portfolio Analysis Tool

Een moderne, responsieve webapplicatie voor portfolio beheer, gebouwd voor GitHub Pages en Progressive Web App (PWA) gebruik.

## Functionaliteiten
- **Transactie Upload**: Inlezen van CSV transactiebestanden.
- **Positie Berekening**: Automatisch berekenen van openstaande posities en gemiddelde aankoopkoersen.
- **Asset Mapping**: Koppel ISIN codes aan Google Finance tickers voor gebruik met Google Sheets / Google Finance.
- **Lokale Persistentie**: Bewaart transacties, mappings en laatste dagprijzen in `localStorage`.
- **PWA Ondersteuning**: Volledig te installeren als app op desktop en mobiel dankzij `manifest.json` en `sw.js`.
